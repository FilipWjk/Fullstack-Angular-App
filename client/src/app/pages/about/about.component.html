About This Project

A comprehensive fullstack example built with Angular 20.x (frontend with SSR) and NestJS (backend) demonstrating CRUD operations, advanced state management, and production-ready tooling.

info Overview

This application is a learning-focused, production-minded sample that showcases a complete CRUD workflow for "cards" with an Angular 20.x SPA frontend featuring SSR and zoneless change detection, and a NestJS REST API backend with comprehensive validation. It includes centralized styling tokens, responsive layouts, comprehensive NgRx state management, and modern development tooling.

build Technical Stack

  • code Angular 20.x (Standalone components, SSR, Zoneless change detection)
  • extension Angular Material (icons, UI primitives)
  • folder_shared NgRx (actions, effects, reducers, selectors, state) for comprehensive state management
  • cloud NestJS + TypeORM for backend API and database access
  • storage PostgreSQL for data persistence with environment-based configuration
  • palette SCSS with centralized variables for consistent theming
  • build_circle Modern tooling: ESLint, Prettier, Jest testing, proxy configuration

folder Repository Layout

The repository follows a split frontend/backend structure:

  • desktop_windows client/ — Angular app (components, pages, services, styles)
  • settings_applications server/ — NestJS API (controllers, services, modules, entities)

How to run

Locally run the frontend and backend in separate terminals:

  • cd client && npm install && ng serve (or npm start)
  • cd server && npm install && npm run start:dev

Backend requires a configured PostgreSQL database with environment variables — check server's README or .env setup for connection details.
